Score Weighting

How CA3 works

Leave at 0 if your school only uses CA1 and CA2. Any value above 0 adds a CA3 column everywhere; setting it back to 0 switches it off again without deleting any CA3 scores already saved.

Tip

The four maximums are usually set to add up to 100 (e.g. CA1 10 + CA2 10 + CA3 10 + Exam 70), but you can use any combination that fits your school's grading rules.
