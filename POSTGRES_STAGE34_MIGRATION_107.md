# Stage 34 — PostgreSQL migration 107: `ai_outputs`

## Reviewed SQLite source

The migration was selected from `postgres_effective_schema_snapshot.json` and checked against the source `CREATE TABLE ai_outputs` definition in `db.py`.

- 15 columns, including `tenant_id`
- No declared foreign keys
- Two non-unique indexes:
  - `idx_ai_outputs_school_feature` on `(school_id, feature, created_at)`
  - `idx_ai_outputs_student` on `(school_id, student_id, term_id)`
- Status constraint: `draft`, `approved`, or `rejected`
- Tenant-stamping trigger fills a missing tenant ID from `schools.tenant_id`

## PostgreSQL implementation

- Added `postgres_migration_107_ai_outputs.py`.
- Uses a `BIGINT GENERATED BY DEFAULT AS IDENTITY` primary key.
- Converts integer identifiers to `BIGINT`.
- Preserves `reviewed_at`, `created_at`, and `updated_at` as `TEXT`.
- Recreates both indexes and the status CHECK constraint.
- Ports tenant stamping to a PostgreSQL `BEFORE INSERT` trigger.
- Validates expected column names/types/nullability, exact index set, absence of foreign keys, and presence of the tenant trigger.
- Registered migration 107 in `postgres_migration_registry.py`.
- Updated previous registry expectations to include migration 107.
