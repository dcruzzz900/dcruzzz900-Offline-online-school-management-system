📄 Result Display Settings

Controls what appears on every result sheet — on-screen preview, print and PDF.

Identity & header

How Passport & Logo work

Logo comes from School Profile. Passport is the student photo on file. Watermark uses the school name (or custom text below) faintly behind the sheet.

School information

Custom fields are managed under Custom School Information.

Student details

How “Next Term Resumes” works

Student name is always shown. “Next Term Resumes” uses the resumption date set for the following term under Sessions & Terms — First Term’s sheet shows Second Term’s date, and so on. It is never typed on this page, and is blank if that term has no date.

Scores

Additional fields are configured under Additional Result Fields.

Attendance

Comments & signatures

How comment suggestions work

When on, a comment is generated from the student’s grade/average if none was typed — useful after CSV score upload. A saved comment is never replaced. Teacher and Principal comments are separate fields.
