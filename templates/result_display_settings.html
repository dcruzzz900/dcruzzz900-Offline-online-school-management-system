Comments

A saved comment is never replaced by a suggestion. Teacher and Principal comments are separate fields with separate permissions.

Cumulative / Annual Result

When ON, the annual result (all terms of the session) becomes available beside the termly result. Existing calculations are unchanged; it follows the same publication rules as termly results.

Resumption date

Set the date for each term under Sessions & Terms (the academic calendar). It appears on the sheet only when “Show Resumption Date” is ON and a date has been set — nothing is invented.
