{# V106: shared Gender Distribution donut + legend -- the exact component the V105 admin dashboard introduced, now reused by every other dashboard/page that shows a gender breakdown so they all inherit the same look instead of keeping a separate implementation (teacher_dashboard.html and admin_analytics.html used to render their own Chart.js donut; both now call this macro instead). Takes plain counts so it works from either admin_dashboard_overview()'s "students"/"staff" dicts (male/female/male_pct/female_pct) or student_gender_stats()'s dict (boys/girls/unspecified) -- see gender_donut_from_stats(). #} {% macro gender_donut(male, female, male_pct, female_pct, male_label='Male', female_label='Female', aria_subject='Students') %}
  • {{ male_label }}{{ '{:,}'.format(male) }} ({{ male_pct }}%)
  • {{ female_label }}{{ '{:,}'.format(female) }} ({{ female_pct }}%)
{% endmacro %} {# Convenience wrapper for the other, older stats shape (student_gender_stats(): boys/girls/ unspecified, no pre-computed percentages) -- so callers don't each re-derive male_pct/female_pct. #} {% macro gender_donut_from_stats(stats, aria_subject='Students') %} {% set total = (stats.boys or 0) + (stats.girls or 0) %} {{ gender_donut(stats.boys or 0, stats.girls or 0, ((stats.boys or 0) * 100 / total)|round if total else 0, ((stats.girls or 0) * 100 / total)|round if total else 0, aria_subject=aria_subject) }} {% endmacro %}
