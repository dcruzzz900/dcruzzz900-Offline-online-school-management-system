# V105 – Modern UI Integrated into School Result System

This package is the full **school-result-system-v104** codebase with the modern My School Hub UI design integrated.

## What was added / updated
- New CSS: `static/css/modern-dashboard.css`, `static/css/modern-ui.css`
- Modernised templates for Dashboard, Students, Staff, Parents, Attendance, Promote,
  Score Entry, Broadsheet, Result Approval, Timetable, Billing, Notifications,
  Student Profile, School Profile, Settings, Reports, Parent Dashboard, Classes,
  Subjects, Assign Subjects, Terms, Grading, Theme Branding, Learning Materials,
  Login, Result Display Settings, Profile Form
- `templates/base.html` loads the new styles globally

## How to run
Same as before (Flask app). After deploy, hard-refresh the browser (Ctrl+Shift+R).

See README.md and existing deployment docs for production setup.
